# Momentum — visual system

The user chose a dark, high-tech interface and delegated visual decisions. The working dashboard uses precise familiar controls; the separate Growth World is a spatial experience. Code-first implementation.

## Direction

A personal growth observatory: graphite surfaces, botanical lime, sharp data typography, restrained ceramic/metal 3D forms. Seven grounded sources considered: contemporary music practice tools; running-club identity systems; university study publications; botanical research exhibitions; industrial design monographs; modern astronomical data displays; performance training journals. Botanical research exhibitions supply the growth mechanism and color relationships, translated to the user's dark high-tech commitment.

The design raises its density discipline from the catalog's exposure records, temporal clarity from notation, typographic confidence from Metro, state continuity from departure boards, whole-cell clarity from catalogs, and meaningful color from transit diagrams. Familiar dashboard navigation and input controls remain standard. No decorative score notation, fake instrument controls, or paper texture.

## Tokens

- Canvas #0c100e; sidebar #0a0d0b; surface #151b17; raised surface #1c241e.
- Main text #eef4e9; secondary #a1afa4; muted #89988d.
- Accent #c0ee82; green #8acb97; red #f28b89; amber #dfbe79; blue #8abadd.
- Borders #2a342d, one-pixel; shadow only on overlays.
- Manrope variable for headings, DM Sans variable for body, self-hosted via npm.
- 12px radius panels, 8px inputs, 6px charts and day cells. Pill only for compact statuses.
- Body 14px, section heading 18px, page heading 30px. Tabular data numerals.

## First viewport

Persistent dark sidebar. Header and period filter. A wide forest-tinted welcome composition with a live 3D garden opposite a concise personal message and clear check-in action. Four compact metric cells below. Contribution history and today's agenda beneath. Each control leads to a functional page or editor.

## Signature

The same visual grammar expands into an actual scrollable Three.js biome. Camera moves across four deterministic, reversible chapter compositions. Reduced motion keeps composed stills and every task remains accessible through semantic HTML.

## App states

Unrecorded values show dashes, not artificial zeros. No seeded progress. Empty calendar remains interactive. Entry saving reports pending, failure, and success. Red/green names and definitions are editable and colors have text equivalents. All fields labeled and optional; choice groups are accessible buttons. Export and import keep personal records portable.
